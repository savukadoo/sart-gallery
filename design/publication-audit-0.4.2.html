Developer setup

  1. Keep TV and development computer on the same trusted network.
  2. Use Samsung's Apps-screen Developer Mode procedure for the target model. Set the development computer's address and fully restart the TV.
  3. Supply the target address and registered model explicitly. Installation tools verify the selected device before access.
  4. Create or reuse the appropriate Samsung author/distributor profile; retain the author identity for updates.
  5. Install, launch and independently verify the features required on that platform.

Example documentation addresses use 192.0.2.10 for a TV and 192.0.2.20 for a development computer. These are reserved examples, not live targets.

Build and validation

See README for setup, build, signing, source and licence instructions. Run the logic/TLS fixtures, Python tests and package checks. Separate physical acceptance covers remote/IME navigation, modal bounds, slideshow motion, uploads, saved state and native Art handoff.

Security and privacy

Keep keys, authorities, profiles, diagnostics and screenshots under ignored private local storage. A public source archive must pass the privacy check and exclude per-device hardware scripts and reports. Never infer successful preservation or native handoff from installer success alone.
