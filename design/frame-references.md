# SART Gallery frame references

Checked 28 October 2026 against Samsung's own material:

- [Samsung The Frame design studio](https://www.samsung.com/sg/lifestyle-tvs/the-frame/design/) shows separate bezel choices and mat options. Its bezel palette includes Brown, Teak, White and Sand gold.
- [Samsung's 2026 lineup announcement](https://news.samsung.com/us/samsung-elevates-2026-frame-lineup-broader-customization-advanced-glare-free-technology/) names Modern Brown, Modern Teak, Modern White and Sand Gold Metal.
- [Samsung Art Mode support](https://www.samsung.com/us/support/answer/ANS10005239/) describes changing mat style and colour for artwork.
- [Samsung's Frame FAQ](https://news.samsung.com/za/the-frame-faq) describes Shadow box, Modern and other mat layouts. It is historical material; it is used as a visual concept reference, not a claim about every current TV's available options.

No Samsung artwork, branded UI, bezel textures or code is copied. Four procedural rails, mitered corners, local colour gradients and directional grain provide the frame effect. Each artwork's frame, mat and fit are saved together in local storage. Adding the frames changes the widget by only a few kilobytes; it does not add a texture download or runtime dependency.
