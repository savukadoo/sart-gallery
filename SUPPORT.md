# Help and support

Start with **Settings → About → Help guide** in SART Gallery, the [README](README.md), and the [engineering guide](design/engineering-handover.html).

Use a GitHub bug report for a reproducible problem or a feature request for an improvement. Include the SART version, Tizen version or browser version, steps to reproduce, expected behaviour and actual behaviour. A general model family is enough for an initial report.

Use a clean screenshot with no personal photographs, connection QR codes, addresses or device identifiers. Remove serial numbers, DUIDs, account details, private network configuration and certificate material from logs. Security problems belong in [private vulnerability reporting](SECURITY.md).

SART is an independent project, not a Samsung product or an official Art Store client. Samsung controls Developer Mode, signing, platform capabilities and native Art Mode. Installation and optional features can vary with model and firmware. A browser preview cannot confirm hardware support.
